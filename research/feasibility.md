## 3. Zero-cost publication toolchain (decision D-003)

There is no TeX distribution. PDFs are produced as Markdown, converted by pandoc to Typst, compiled with the typst Python package; `manuscript.tex` is generated from the same Markdown by pandoc for portability and is not compiled locally. PDFs are inspected with pypdf (text extraction, page count) and visually.

Exploratory toolchain smoke check (not research evidence): a three-line Markdown file with inline math and a table converted to `.typ` and `.tex`. The first compile failed with `typst.TypstError: font fallback list must not be empty`, because pandoc's default Typst template writes `font: ()` when no font is given. With `-V mainfont="Libertinus Serif"` the compile succeeded: one page, text extraction returned the heading, the math and the table. The working files were kept in the session scratch directory, outside the repository.

## 5. Compute estimate (planning estimate, not a measurement)

EXP-002: 72 arms $\times$ 10,000 episodes $\times$ 50 agents = 36 million agent decisions. The Bayesian `window-k` rule needs a forward recursion over at most $2^3 = 8$ window states per agent per state value, vectorisable across episodes with numpy. EXP-003 adds about 1.5 times that volume. An order-of-magnitude expectation is minutes to tens of minutes on one core; the actual runtime will be measured in EXP-001 and recorded before the full matrix is launched. Memory is negligible (per-episode summaries only; raw per-agent traces kept for a small fixture subset).

## 6. Sources and data

The study uses synthetic data only, generated by a seeded simulator. No dataset needs to be downloaded or redistributed. Candidate external data considered and its status are in `data/manifest.json` and `research/literature_review.md`.

## 7. Cost

No paid service, API, dataset, compute or hosting. All dependencies are free and locally installed or resolved from PyPI (numpy BSD-style licence; pytest MIT licence, per PyPI metadata read on 2026-11-24).

## 8. Scope, exclusions and fallback

- In scope: binary state, binary signals, sequential single actions, three rules, two network families, two visibility levels.
- Excluded: human participants, real behavioural data, continuous signals, heterogeneous preferences, repeated actions, general random graphs (exact Bayesian inference there is not tractable within budget).
- Fallback: if the exact `window-3` Bayesian recursion proves too slow or cannot be verified, the network factor is reduced to {complete, window-2}, and this is recorded as an amendment (amendment A-1, owner-approved 2026-11-24, replaced the earlier fallback {complete, window-1}, since `window-1` is degenerate).
