# results/

Machine-readable experiment outputs with run manifests.

- `exploratory/`: exploratory runs only (EXP-001-R001 to R004, M2). Planning and verification measurements, never evidence for a study hypothesis. Each run folder holds `result.json` (schema `result-v1`), `run_manifest.json`, `tables/`, `figures/`, `report.md` and `report.pdf`, all generated by `python -m herd.cli run` and `report`.
- `raw/`: per-episode arrays (`episodes.npz`). Exploratory raw arrays are git-ignored and regenerated by rerunning the configuration; the confirmatory raw arrays `raw/EXP-002-R001/` and `raw/EXP-003-R001/` are committed (D-010).
- `EXP-002/EXP-002-R001/`, `EXP-003/EXP-003-R001/`: confirmatory runs of the frozen protocols v1.0 (2026-11-25), same layout as the exploratory runs; `EXP-003-R001/tables/robustness_vs_EXP-002-R001.csv` applies the EXP-003 decision rule. `EXP-00N/SHA256SUMS` lists the SHA-256 of every file of the run, raw arrays included (`shasum -a 256 -c` from the repository root).
- `exploratory/EXP-004-R001/`: M4 exploratory, post-hoc run of the EXP-003 design on $q \in \{0.60, 0.80\}$; `tables/robustness_vs_EXP-002-R001.csv` applies the unchanged EXP-003 rule. Raw arrays git-ignored (regenerable).
- `exploratory/EXP-004-derived/`: M4 exploratory analyses computed from the committed EXP-002-R001 and EXP-003-R001 raw arrays (`python -m herd.exploratory`); `summary.json` records input and output SHA-256 and the code revision.
