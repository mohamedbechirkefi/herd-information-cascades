# results/

Machine-readable experiment outputs with run manifests.

- `exploratory/`: exploratory runs only (EXP-001-R001 to R004, M2). Planning and verification measurements, never evidence for a study hypothesis. Each run folder holds `result.json` (schema `result-v1`), `run_manifest.json`, `tables/`, `figures/`, `report.md` and `report.pdf`, all generated by `python -m herd.cli run` and `report`.
- `raw/`: per-episode arrays (`episodes.npz`), git-ignored and regenerated by rerunning the configuration.
- Confirmatory results (EXP-002, EXP-003) will be written to `results/EXP-00N/` only after the owner freezes the protocols; the runner refuses them before that.
